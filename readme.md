# Lava Game Engine
an developing 2D and 3D game engine which is written in C#

## Start

### Installing
Lava Engine is a new engine that did not have any release version yet. In the future, you can install LavaEngine on https://github.io/LavaGameStudios/.

### Compiling
Although we don't have release version yet, but if want to help developing LavaEngine, you can download the repository of LavaGameEngine and compile it.

#### What is required for compiling the engine
* dotnet 10


#### Compiling the Engine on Windows
Step 1: clone the engine using the command
```
git clone --recursive https://github.com/LavaGameStudios/LavaEngine.git
```
